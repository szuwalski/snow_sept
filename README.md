# EBS snow crab — September 2026 SAFE

Assessment and SAFE report for **eastern Bering Sea snow crab (*Chionoecetes opilio*)**, September 2026
cycle. This assessment sets federal fishery reference points (OFL/ABC), so **accuracy and
reproducibility are the priority** for every step here.

Authors: Grant Adams and Cody Szuwalski. Inherited from the May 2026 CPT/model-selection work
(`snow_crab` repo) and ported onto its portable R Markdown architecture.

---

## How to run (from repo root)

```powershell
$RS = "C:/Program Files/R/R-4.5.1/bin/x64/Rscript.exe"
& $RS 01_prep_fishery_data.R        # rebuild fishery-removal inputs in data/derived/
& $RS 02_prep_survey_data.R         # crabpack pull + rebuild survey size-comp / maturity / growth inputs
#   -> hand-paste the data/derived/ outputs into the model .DAT, then run gmacs.exe in the model dir
& $RS 03_build_results_object.R     # rebuild Models/rda_ModelsResLst.RData
& $RS 04_plot_recruitment_comparison.R; & $RS 05_run_jitter.R; & $RS 06_run_retrospective.R; & $RS 07_calc_tier4.R
#   jitter BEFORE retrospective: a promotion changes the fit and invalidates any peels run first
& $RS 08_render_report.R            # render 2026_snowcrab_safe_draft.Rmd -> PDF
```

The `.DAT` build (scripts 01/02) still ends in a **manual paste** step into the model `.DAT` file —
this is Cody's existing workflow and is flagged in-script for future automation.

  in metric tons. See `docs/EMAIL_to_tyler.md` for an outstanding query on a 1990–1993 retained-comp
  correction in the 2025/26 delivery.

- **NORPAC** bycatch length/catch reports: download to `data/norpac_*_report/` (see their README.txt).
